# Modern.js

Modern.js 团队维护的 `@modern-js/storybook-addon` 使用应用自身的配置解析 API，让 Storybook 预览复用应用配置。

## 快速开始

查看 [Modern.js React 示例](https://github.com/rstackjs/storybook-rsbuild/tree/v4/sandboxes/modernjs-react)，了解该集成在真实项目中的用法。

### 安装

<PackageManagerTabs command="install @rsbuild/core storybook-builder-rsbuild storybook-react-rsbuild @modern-js/storybook-addon -D" />

请在 Modern.js 应用所在的 workspace 安装这些包。选择 peer 依赖覆盖当前 builder 和 `@modern-js/app-tools` 的 addon 版本。addon 需要 app-tools 公开导出的 `resolveModernRsbuildConfig`，`@rsbuild/core` 的版本也应与 app-tools 使用的版本一致。

### 配置 `.storybook/main.ts`

```ts twoslash title=".storybook/main.ts"
// @noErrors
import type { StorybookConfig } from 'storybook-react-rsbuild'

const config: StorybookConfig = {
  stories: ['../src/**/*.stories.@(js|jsx|mjs|ts|tsx)'],
  addons: ['@modern-js/storybook-addon'],
  framework: 'storybook-react-rsbuild',
}
export default config
```

addon 会合并公共配置与 `environments.client`，然后按 [Builder 选项](/guide/configuration#builder-选项) 中的规则过滤配置。如需在 Storybook 中显式设置被过滤的字段，请在 `rsbuildFinal` 中添加。

## 结合 Module Federation

完整流程请参阅 [Module Federation 示例](https://github.com/rstackjs/storybook-rsbuild/tree/v4/sandboxes/modernjs-react-mf)。

### 安装

如果你的 Modern.js 应用使用了 Module Federation，请安装 `@module-federation/storybook-addon`。

<PackageManagerTabs command="install @module-federation/storybook-addon -D" />

### 配置 `.storybook/main.ts`

添加该 addon 并手动传入 `remotes` 选项。Storybook 无法自动推断它。

```ts twoslash title=".storybook/main.ts"
// @noErrors
import type { StorybookConfig } from 'storybook-react-rsbuild'
// import moduleFederationConfig from '../module-federation.config'
const moduleFederationConfig = { remotes: {} }

const config: StorybookConfig = {
  stories: ['../src/**/*.stories.@(js|jsx|mjs|ts|tsx)'],
  addons: [
    '@modern-js/storybook-addon',
    {
      name: '@module-federation/storybook-addon',
      options: {
        remotes: moduleFederationConfig.remotes,
      },
    },
  ],
  framework: 'storybook-react-rsbuild',
}
export default config
```

### 配置 `modern.config.ts`

使用 `@module-federation/storybook-addon` 时，请在 Storybook 运行期间于 `modern.config.ts` 中禁用 `moduleFederationPlugin`。

一种做法是检查由你的 Storybook 脚本设置的环境变量。

```json title="package.json"
{
  "scripts": {
    "storybook": "STORYBOOK=true storybook dev -p 6006"
  }
}
```

```ts title="modern.config.ts"
import { appTools, defineConfig } from '@modern-js/app-tools'
import { moduleFederationPlugin } from '@module-federation/modern-js-v3'

// https://modernjs.dev/en/configure/app/usage
export default defineConfig({
  plugins: [
    appTools(),
    ...(process.env.STORYBOOK === 'true' ? [] : [moduleFederationPlugin()]),
  ],
})
```

## 局限性

Modern.js 拥有自己的 plugin 系统，会在将配置交给 Rsbuild 之前对其进行转换。

Modern.js 还会在内部处理用户配置，在 Rsbuild 看到结果之前执行复杂的改动。

:::tip
因此，该 addon 在 Modern.js 中存在一些局限性。
:::

### 🎗 支持的用法

- Modern.js 配置文件
- 用于修改配置的 Modern.js plugin
- Rsbuild plugin

### 😪 不支持的用法

- 不能使用 webpack，仅支持 Rspack
- SSR 配置在 Storybook 中不会生效
- 运行时能力，例如 `<Link>` 导航
