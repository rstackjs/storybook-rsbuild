## Getting started

Follow these steps inside an existing Rsbuild-powered React project.

### Installation

Install the framework package and `@rsbuild/core`. Even though `storybook-react-rsbuild` declares `@rsbuild/core` as a peer, list it as a direct dev dependency so version pins and lockfile audits remain unambiguous.

<PackageManagerTabs command="install @rsbuild/core storybook-react-rsbuild -D" />

### Configure `.storybook/main.ts`

```js
import { StorybookConfig } from 'storybook-react-rsbuild'
import { mergeRsbuildConfig } from '@rsbuild/core'

const config: StorybookConfig = {
  framework: 'storybook-react-rsbuild',
  stories: ['../src/**/*.stories.@(js|jsx|mjs|ts|tsx)'],
  rsbuildFinal: (config) => {
    // Customize the final Rsbuild config here
    return mergeRsbuildConfig(config, {
      // your custom config
    })
  },
}

export default config
```

That's it! Explore the [React 18](https://github.com/rstackjs/storybook-rsbuild/tree/main/sandboxes/react-18) sandbox for a full example, and continue learning from the [Storybook documentation](https://storybook.js.org/docs).
